# Egg-Counting-System
# 🥚 AI Egg Counting & Monitoring System
Mask R-CNN based egg detection and counting for factory automation.

## Features
- Upload **Image** or **Video**
- AI detects each egg with **red mask** + **green bounding box**
- **ROI Box** — only eggs entering the box are counted
- **Live counter** during video processing
- **Download** processed output
